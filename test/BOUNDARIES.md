Kotlin fills omitted `caption` with an empty string, `areas` with an empty list, and object `ball` with false; nullable properties normalise to omission when encoded. JS retains authored absence/null. Compare authored non-null values and each parser's stable round trip, rather than requiring byte-identical optional-default encoding. Drawing numbers use binary64 precision. Malformed JSON and non-finite direct JS objects are tested separately because they are not JSON fixtures.
